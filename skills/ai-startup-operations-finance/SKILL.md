## 🎯 核心理念

**运营 = 把战略变结果。**

1. **谁来做**（组织 + 角色）

## 🏢 组织设计

### 4 阶段组织演进

#### 阶段 1：创始人驱动（1-5 人）
```
创始人
  ├─ 1-2 个核心成员
  └─ 兼职 / 外包
```
- 创始人全栈
- 决策极快
- 文化靠言传身教

#### 阶段 2：职能分工（5-20 人）
```
创始人
  ├─ 产品 (1-2)
  ├─ 技术 (3-8)
  ├─ 销售 (1-3)
  ├─ 运营 (1-2)
  └─ 行政财务 (1)
```

#### 阶段 3：业务线（20-100 人）
- 业务线独立经营
- 平台部门支撑
- 创始人退到战略

#### 阶段 4：集团化（100+ 人）
- CEO + COO + CFO + CTO
- 多个业务线

## ⚙️ 流程优化

### 流程设计 5 原则

1. **目标导向**：每个流程有明确目标
2. **简化优先**：步骤越少越好
3. **自动化**：能自动就自动
4. **可视化**：流程透明可查
5. **持续改进**：定期复盘

### 流程 4 步法

1. **梳理现状**：画流程图
2. **识别瓶颈**：找到最慢/最贵的环节
3. **优化方案**：砍掉/合并/自动化
4. **效果评估**：用数据验证

### 核心流程清单

| 流程 | 周期 | 关键步骤 |
|------|------|---------|
| 招聘 | 30 天 | JD → 筛选 → 面试 → Offer |
| 销售 | 30-90 天 | Lead → Demo → 谈判 → 签约 |
| 客户成功 | 持续 | onboarding → 培训 → 续约 |
| 财务 | 月度 | 入账 → 对账 → 报表 |
| 产品 | 季度 | 规划 → 开发 → 发布 |

## 💰 财务预算

### 3 大财务报表

#### 1. 利润表（P&L）
```
收入 - 成本 = 毛利
毛利 - 费用 = 营业利润
营业利润 ± 营业外 = 净利润
```

#### 2. 资产负债表（BS）
```
资产 = 负债 + 所有者权益
```

#### 3. 现金流量表（CF）
```
经营 ± 投资 ± 融资 = 现金净变动
```

### 关键财务指标

| 指标 | 公式 | 健康值 |
|------|------|--------|
| **毛利率** | (收入-成本)/收入 | > 60% (SaaS) |
| **净利率** | 净利润/收入 | 增长中 |
| **现金燃烧率** | 月现金支出 | 越低越好 |
| **跑道** | 现金/燃烧率 | > 12 月 |
| **回本周期** | CAC/月毛利 | < 12 月 |

## 💵 现金流管理

### 现金流 3 大原则

1. **收入早收**：催收账款 / 预收款
2. **支出晚付**：延后支付 / 分期
3. **预算控制**：不要超预算

### 12 月现金流预测

```
1 月：____
2 月：____
...
12 月：____
期末现金：____
```

### 现金流危机信号

- ⚠️ 跑道 < 6 月
- ⚠️ 客户回款 > 90 天
- ⚠️ 应收账款 > 月收入 50%
- ⚠️ 每月现金净流出

### 应对措施

| 信号 | 措施 |
|------|------|
| 跑道 < 6 月 | 立即融资 / 削减成本 |
| 回款慢 | 加强催收 / 缩短账期 |
| 应收高 | 客户分级 / 预收款 |
| 月流出 | 砍项目 / 增收入 |

## 🏗️ 团队管理

### 招聘 4 步法

1. **需求明确**：岗位 JD + 关键能力
2. **渠道多元**：内推 + 招聘 + 主动挖
3. **面试结构化**：初试 + 复试 + 终试
4. **Offer 谈判**：薪资 + 期权 + 文化

### 薪酬结构

| 层级 | 现金 | 期权 | 特点 |
|------|------|------|------|
| 早期员工 | 高 | 高 | 期权有未来 |
| 中期员工 | 中 | 中 | 平衡 |
| 后期员工 | 高 | 低 | 现金为主 |

### 绩效管理 OKR

```
O: 提升客户留存
   KR1: 30 天留存 60% → 75%
   KR2: 90 天留存 40% → 60%
   KR3: 续约率 70% → 85%
```

- **愿景**：我们要成为什么

## 💡 运营 5 大反常识

### 1. 少人高效 > 多人低效
> 5 个精兵 > 20 个庸才。

### 2. 流程越简单越好
> 流程 = 协作成本。流程多 = 速度慢。

### 3. 现金流 > 利润
> 有利润但没现金 = 死。有现金但没利润 = 调整。

### 4. 关键岗位 1 个备份
> 关键岗位没备份 = 创始人永远救火。

### 5. 文化是筛选出来的
> 文化不是宣传的，是招聘时筛选的。
