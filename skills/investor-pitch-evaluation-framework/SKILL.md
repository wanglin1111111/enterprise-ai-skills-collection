# 投资人路演评估框架

> **6 维评分卡 × 估值锚定方法 × 决策矩阵 × 红线检查清单**
>
> 帮助投资人/评委/孵化器：
> - 5 分钟内对路演项目做完整评估
> - 区分"看似惊艳"和"真问题真解法"
> - 用评分卡替代主观判断
> - 在投不投之间做出可解释的决策

---

## 🎯 核心理念

**路演不是表演赛，是信号提取赛。**

5 分钟内能提取的有效信号 ≈ 真实价值的 60-70%。其余 30% 需要尽调。

投资人要做的不是"听懂项目"，而是"提取信号"：
- 信号 1：项目在解决**真实问题**还是**想象中的问题**
- 信号 2：团队是**有真东西**还是**讲故事**
- 信号 3：市场是**真实存在**还是**假设存在**
- 信号 4：商业模式是**已验证**还是**PPT 推演**
- 信号 5：壁垒是**真实可复制**还是**空中楼阁**

---

## 📊 6 维评分卡

### 评分维度（每项 0-10 分）

| 维度 | 0-3 分（差）| 4-6 分（中）| 7-10 分（优）|
|------|-------------|-------------|-------------|
| **痛点真实度** | 自嗨 | 客户访谈过但未付费 | 客户已用土办法 + 等不及了 |
| **解决方案匹配度** | 概念 PPT | 已有 Demo | 已落地 + 客户复购 |
| **团队完整度** | 创始人单干 | 缺 1-2 个关键角色 | 全栈团队 + 行业资源 |
| **市场规模** | 看不清晰 | 有 TAM 但偏小 | TAM > 100 亿 + SAM 真实可触达 |
| **商业模式** | 纯烧钱 | 已有付费但 ARR 小 | 单位经济模型已跑通 |
| **壁垒深度** | 无壁垒 | 有先发优势 | 数据/网络/规模/合规 至少 1 个真壁垒 |

### 总分判定

| 总分 | 评级 | 建议 |
|------|------|------|
| 48-60 | **S** | 立即跟进，抢份额 |
| 36-47 | **A** | 重点跟进，做尽调 |
| 24-35 | **B** | 观察，二轮再评 |
| 0-23 | **C** | 不跟进 |

## 🎯 5 分钟信号提取流程

### 第 1 分钟：听"故事"（30 秒内做判断）

- [ ] 客户是谁？（具体到行业 + 规模 + 角色）
- [ ] 痛点是什么？（用客户自己的语言）
- [ ] 现有方案是什么？（必须是"已经有"而不是"没有"）
- [ ] 为什么是现在？（技术拐点 / 政策变化 / 成本变化）

**关键判断**：如果 4 个问题中 3 个答不清楚，直接 B 评级以下。

### 第 2 分钟：看"数字"（30 秒内做判断）

| 关键数字 | 问什么 |
|---------|--------|
| **已付费客户数** | 至少 5 个，最好 10+ |
| **ARR / GMV** | 至少百万级 |
| **客户复购率** | > 60% 是健康，< 30% 是危险 |
| **CAC / LTV** | LTV > 3 × CAC |
| **毛利率** | 至少 50%，硬件 < 30% 需自圆其说 |
| **现金流** | 还有几个月 runway |

**关键判断**：没有真实数字 = 没有真实业务。

### 第 3 分钟：问"团队"（30 秒内做判断）

- 创始人背景：连续创业？行业老兵？技术天才？资源型？
- 团队配置：技术/产品/销售/运营 各有负责人？
- 互补性：核心 3 人是同质化还是互补？
- 投入度：全职还是兼职？

**关键判断**：单创始人 + 兼职团队 = 风险极高。

### 第 4 分钟：探"壁垒"（30 秒内做判断）

- [ ] 别人能不能 6 个月内复制？
- [ ] 数据壁垒是否存在且能持续积累？
- [ ] 网络效应是否存在？
- [ ] 规模效应是否存在？
- [ ] 监管/资质壁垒是否存在？

**关键判断**：5 项全否 = 没有壁垒。

### 第 5 分钟：定"估值"（30 秒内做判断）

| 估值方法 | 适用场景 |
|---------|---------|
| **P/S 倍数** | 早期 SaaS（5-15x） |
| **P/E 倍数** | 成熟期（15-30x） |
| **可比交易** | 有同期类似融资 |
| **DCF** | 现金流稳定 |
| **成本反推** | 团队 + 18 个月 runway + 一定 buffer |

**核心原则**：估值要锚定到下一轮。如果按你的估值 18 个月后涨不回来 = 估值过高。

## 🚦 红线检查清单

### 一票否决项

- [ ] **法律红线**：涉黄赌毒 / 传销 / 资金盘 / 违规金融
- [ ] **道德红线**：创始人有重大诚信问题
- [ ] **健康红线**：核心团队有重大健康风险未披露
- [ ] **技术红线**：核心专利 / 知识产权有争议

### 严重警告项

- [ ] 数据前后矛盾（用户数 / 收入 / 客户数 对不上）
- [ ] 团队频繁变动（前 6 个月 > 30% 离职）
- [ ] 现金流即将断裂（< 3 个月 runway）
- [ ] 创始人避谈关键问题
- [ ] 客户案例无法验证（拒绝引荐）

## 📈 决策矩阵

### 投 / 不投 / 继续观察

```
            高潜力（评分≥36）
                ↑
                |
    抢份额 ←——+——→ 重点跟进
     (立即)    |    (1周内尽调)
                |
低确定性 ←——+——→ 高确定性
     (不投)    |    (但天花板低)
                |    (谨慎)
                ↓
            低潜力（评分<24）
```

### 估值博弈

| 你的出价 | 创始人接受条件 |
|---------|--------------|
| **低于合理估值 30%** | 需占股 15-20% |
| **低于合理估值 10%** | 需占股 10-15% |
| **等于合理估值** | 需占股 5-10% |
| **高于合理估值 20%** | 需占股 < 5%（一般不做） |

**反锚定策略**：永远先让创始人报价，再砍 30-50%。

## 🧪 实战评分模板

### 假设项目背景

> "我们做 AI 帮新能源电站提升发电效率 5%"

### 6 维评分

| 维度 | 分数 | 依据 |
|------|------|------|
| 痛点真实度 | 8/10 | 5% 效率 = 千万级年收益，电站主愿意付费 |
| 解决方案匹配度 | 6/10 | 有 Demo，但尚未落地 |
| 团队完整度 | 7/10 | 有 AI 专家 + 能源行业销售 |
| 市场规模 | 8/10 | 中国新能源电站 > 10 万个，TAM 千亿级 |
| 商业模式 | 5/10 | 按发电量分成，但尚未验证 |
| 壁垒深度 | 6/10 | 有数据壁垒雏形，但可被复制 |
| **总分** | **40/60** | **A 级，重点跟进** |

### 跟进动作
1. 1 周内安排客户访谈（验证 5% 效率提升真实性）
2. 2 周内要求看技术 Demo 演示
3. 3 周内做竞品分析（是否有大厂在做）
4. 1 个月内出 TS

## 🎓 反模式警告

### ❌ "赛道很好，团队差一些没关系"
错。赛道是充分条件，团队是必要条件。团队不行 = 钱打水漂。

### ❌ "估值贵一点没关系，先占坑"
错。估值过高 = 下一轮接盘侠难找 = 创始人失去动力 = 双输。

### ❌ "等下一轮估值涨了再投"
错。早期投资的 alpha 在于**第一轮进得早**。等下一轮 = 没 alpha。

### ❌ "创始人说得好，应该靠谱"
错。路演是表演，真实经营是另一回事。要看数字，不要看表演。

### ❌ "我们看不懂就不投了"
错。看不懂 = 可能是 alpha。但要承认自己看不懂，而不是否定项目。

## 🔍 信号 vs 噪音识别

### 高信噪比信号 ✅
- 客户已付费（最强信号）
- 创始人有行业 5+ 年经验
- 客户主动找上门
- 团队全职 + 加班
- 竞品已出现（说明市场真实）
- 已有竞争对手拿到融资

### 低信噪比噪音 ❌
- "颠覆性创新"
- "万亿级市场"
- "我们是中国版 XX"
- "头部公司都在做但我们更懂"
- "未来 3 年做到 100 亿"
- PPT 制作精良

---

## 💡 一句话决策原则

> **早期投资 = 投人 + 投问题。** 解决方案可以迭代，团队不行一切归零。
> **数据 > PPT，复购 > 演示，现金流 > 估值。**
> **看不懂的不投，看得懂但太贵的不投。**
