# 投资人路演评估框架

> 6 维评分卡 + 5 分钟信号提取 + 红线检查 + 估值博弈

## 核心观点

**路演不是表演赛，是信号提取赛。**

5 分钟内能提取的有效信号 ≈ 真实价值的 60-70%。

## 文件清单

- `SKILL.md` — 完整方法论（6 维评分 + 决策矩阵 + 反模式）
- `QUICKREF.md` — 速查卡
- `TEST.md` — 3 个行业案例验证

## 6 维评分卡

| 维度 | 权重 |
|------|------|
| 痛点真实度 | 0-10 |
| 解决方案匹配 | 0-10 |
| 团队完整度 | 0-10 |
| 市场规模 | 0-10 |
| 商业模式 | 0-10 |
| 壁垒深度 | 0-10 |

**总分 48+ S** / 36-47 A / 24-35 B / <24 C

## 5 分钟流程

1. **故事** (30s)：4 问判断
2. **数字** (30s)：6 关键指标
3. **团队** (30s)：背景 / 配置 / 投入度
4. **壁垒** (30s)：5 项可复制性
5. **估值** (30s)：锚定下一轮
