# AI 创业营销 GTM

> **GTM 策略 × 增长引擎 × 获客渠道 × 品牌定位 × 内容营销**
>
> 帮 CMO/营销负责人：
> - 设计 GTM 策略
> - 选择正确的获客渠道
> - 搭建增长引擎
> - 建立品牌护城河

---

## 🎯 核心理念

**GTM = Go To Market = 产品如何从 0 到 1 到 N。**

3 大问题：
1. **卖给谁**（ICP 客户画像）
2. **凭什么买**（价值主张）
3. **怎么找到**（渠道 + 信息）

不解决这 3 个问题 = 营销失焦。

---

## 🎯 ICP 客户画像

### 5 维 ICP 框架

| 维度 | 问题 | 示例 |
|------|------|------|
| **行业** | 哪个行业？ | 金融 / 医疗 / 教育 |
| **规模** | 什么规模公司？ | 100-1000 人 |
| **角色** | 谁决策？谁使用？ | CTO 决策 / 工程师使用 |
| **痛点** | 最大痛点是什么？ | 成本高 / 效率低 |
| **预算** | 预算范围？ | 10-50 万/年 |

### ICP 模板

```
客户画像：[名称]
行业：____
规模：____
角色：____
痛点：____
预算：____
触达渠道：____
转化路径：____
```

### 5 个 ICP 验证问题

1. 客户在公开场合说有这个痛点吗？
2. 客户已经在用替代方案了吗？
3. 客户有预算吗？
4. 客户能决策吗？
5. 我们能触达吗？

**5 个"是"**：明确 ICP
**3-4 个"是"**：可尝试
**< 3 个"是"**：重新选择

## 💎 价值主张设计

### 价值主张画布

```
客户工作        痛点           收益
(Job)         (Pains)        (Gains)
   ↓             ↓             ↓
[              价值主张            ]
   ↑             ↑             ↑
痛点缓解        创造收益
(Pain Relief)  (Gain Creator)
```

### 5 维价值评估

| 维度 | 含义 | 优秀 |
|------|------|------|
| **重要性** | 对客户多重要 | 生死问题 |
| **满意度** | 现有方案满意度 | < 5/10 |
| **市场规模** | 客户基数 | 万级+ |
| **可达性** | 我们能否触达 | 容易 |
| **付费意愿** | 客户付费意愿 | 强 |

### 价值主张模板

```
对 [客户]
我们的产品 [产品名]
是 [产品类别]
提供 [核心价值]
不同于 [替代方案]
我们 [独特优势]
```

### 案例（脱敏）

```
对：跨境电商运营者
产品：AI 多语言客服工具
类别：SaaS 工具
价值：30+ 语言自动化客服
不同于：人工客服（贵）+ 通用翻译（不准）
优势：垂直行业 know-how
```

## 🚀 GTM 4 大模式

### 模式 1：销售驱动（SLG）

**适用**：高客单价 / 复杂产品 / B 端

| 指标 | 范围 |
|------|------|
| 客单价 | 50 万+ |
| 销售周期 | 3-12 月 |
| CAC | 5-20 万 |
| LTV | 100-500 万 |
| 获客渠道 | 销售外呼 / 行业大会 / 客户转介 |

**关键动作**：
- 建立销售团队
- CRM 系统
- 销售话术 + 案例库
- 客户成功团队

---

### 模式 2：产品驱动（PLG）

**适用**：低门槛 / 自助 / C 端/小 B

| 指标 | 范围 |
|------|------|
| 客单价 | 1k-5 万/年 |
| 销售周期 | 即时-1 月 |
| CAC | 100-1000 |
| LTV | 1-20 万 |
| 获客渠道 | 内容 / SEO / 社区 / 口碑 |

**关键动作**：
- 免费版/试用
- 自助注册流程
- 引导 onboarding
- 用户社区

---

### 模式 3：营销驱动（MLG）

**适用**：中等客单价 / 标准化 / 中型 B 端

| 指标 | 范围 |
|------|------|
| 客单价 | 5-50 万 |
| 销售周期 | 1-3 月 |
| CAC | 1-5 万 |
| LTV | 20-200 万 |
| 获客渠道 | 营销自动化 / 内容 / 活动 / 销售跟进 |

**关键动作**：
- 内容营销（公众号 / 视频）
- 营销自动化（邮件 / 短信）
- 行业活动赞助
- SDR 团队（销售开发）

---

### 模式 4：生态驱动（ELG）

**适用**：平台型 / 多边 / 需要合作伙伴

| 指标 | 范围 |
|------|------|
| 客单价 | 不定 |
| 销售周期 | 长期 |
| CAC | 合作分成 |
| LTV | 长期 |
| 获客渠道 | 渠道商 / 集成 / 联盟 |

**关键动作**：
- 渠道商计划
- 集成市场
- 联盟营销
- 联合解决方案

## 📣 获客渠道

### 4 类核心渠道

| 渠道 | 类型 | 成本 | 周期 | 适合 |
|------|------|------|------|------|
| **内容营销** | 长期 | 中 | 6-12 月 | 全行业 |
| **付费广告** | 短期 | 高 | 即时 | 标准化 |
| **销售外呼** | 中期 | 中 | 1-3 月 | B 端 |
| **生态合作** | 长期 | 低 | 6-12 月 | 平台 |

### 渠道 ROI 矩阵

| 渠道 | CAC | 转化率 | 周期 | 评分 |
|------|-----|--------|------|------|
| 内容营销 | 中 | 中 | 长 | ★★★★ |
| 付费广告 | 高 | 高 | 短 | ★★★ |
| 销售外呼 | 中 | 高 | 中 | ★★★★ |
| 行业活动 | 中 | 中 | 中 | ★★★ |
| 客户转介 | 低 | 高 | 长 | ★★★★★ |
| 渠道商 | 低 | 中 | 长 | ★★★★ |

### 早期 0 阶段渠道优先级

1. **客户转介**（最便宜、最精准）
2. **创始人个人 IP**（最高效）
3. **行业社群**（最快进入）
4. **付费搜索**（最确定）
5. **行业活动**（最权威）

## 💰 定价策略

### 4 大定价模式

| 模式 | 适合 | 优缺点 |
|------|------|--------|
| **免费 + 增值** | PLG | 大量用户 + 转化难 |
| **订阅** | SaaS | 稳定 + 复购高 |
| **一次性** | 工具 | 简单 + 复购低 |
| **按用量** | API | 公平 + 难预测 |

### 定价 3 步法

1. **成本定价**：成本 × 3 = 起步
2. **市场定价**：看竞品定价
3. **价值定价**：根据客户价值调整

### 价格层级

```
免费版 / Freemium → 入门版 ($X/月) → 专业版 ($Y/月) → 企业版 (定制)
   获客              转化            主力收入           大客户
```

### 价格歧视

- 年付 8 折
- 多年付 7 折
- 创业公司 5 折
- 教育/非营利 5 折

|------|------|------|------|
| **公众号** | 微信 | 周 1 | 高 |

### 内容选题 5 法

1. **痛点选题**：客户最常问的问题
2. **数据选题**：行业数据 + 趋势
3. **案例选题**：真实客户故事

5. **观点选题**：行业判断 + 预测

```
曝光 → 阅读 → 关注 → 注册 → 试用 → 付费

渠道   内容   CTA   表单   onboarding  销售
```

## 🧮 营销 ROI 测算

### 关键公式

```
CAC = 营销总成本 / 新增客户数
LTV = ARPU × 毛利率 / 流失率
LTV/CAC > 3 = 健康
回本周期 = CAC / 月度 ARPU 毛利
```

### 营销漏斗

```
曝光 1000
   ↓ (10% 点击率)
点击 100
   ↓ (20% 注册率)
注册 20
   ↓ (50% 激活率)
激活 10
   ↓ (30% 付费率)
付费 3

CAC = 1000 元 / 3 = 333 元
```

### 渠道 ROI 对比

| 渠道 | 成本 | 转化 | 客户 | CAC |
|------|------|------|------|-----|
| 内容 | 10 万 | 100 注册 | 5 付费 | 2 万 |
| 付费 | 10 万 | 500 注册 | 8 付费 | 1.25 万 |
| 销售 | 10 万 | 30 注册 | 6 付费 | 1.67 万 |
| 转介 | 1 万 | 20 转介 | 5 付费 | 0.2 万 |

**最优渠道**：转介（CAC 最低）

## 💡 营销 5 大反常识

### 1. 客户成功 = 营销胜利
> 最好的营销 = 现有客户转介。

### 2. 少渠道 > 多渠道
> 集中资源打透 1-2 个渠道，比铺 10 个有效。

### 3. 内容 ROI 滞后 6-12 月
> 内容营销前期没效果，6-12 月才显威力。

### 4. 创始人 IP > 公司品牌
> 早期 = 创始人个人 IP，公司品牌靠后。

### 5. 不做品牌 = 长期价格战
> 品牌 = 定价权。没品牌 = 同质化 = 价格战。
