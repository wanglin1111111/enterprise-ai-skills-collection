# AI 创业营销 GTM - 快速参考

## 🎯 3 大问题

1. 卖给谁（ICP 客户画像）
2. 凭什么买（价值主张）
3. 怎么找到（渠道 + 信息）

## 🎯 ICP 5 维

行业 / 规模 / 角色 / 痛点 / 预算

5 个"是"= 明确 / 3-4= 尝试 / <3= 重新选择

## 💎 价值主张模板

```
对 [客户]
我们的产品 [产品名]
是 [产品类别]
提供 [核心价值]
不同于 [替代方案]
我们 [独特优势]
```

## 🚀 4 大 GTM 模式

| 模式 | 客单价 | 周期 | 适合 |
|------|--------|------|------|
| SLG 销售 | 50万+ | 3-12月 | 高客单/复杂 |
| PLG 产品 | 1k-5万 | 即时-1月 | 低门槛 |
| MLG 营销 | 5-50万 | 1-3月 | 标准化 |
| ELG 生态 | 不定 | 长期 | 平台 |

## 📣 渠道 ROI

| 渠道 | 评分 |
|------|------|
| 客户转介 | ★★★★★ |
| 内容营销 | ★★★★ |
| 销售外呼 | ★★★★ |
| 渠道商 | ★★★★ |
| 付费广告 | ★★★ |
| 行业活动 | ★★★ |

## 📈 增长 3 飞轮

- 内容飞轮：内容 → 用户 → 转化 → 反馈
- 产品飞轮：用户 → 数据 → 产品 → 用户
- 销售飞轮：销售 → 客户 → 案例 → 销售

## 💰 定价 3 步法

1. 成本定价（成本 × 3）
2. 市场定价（看竞品）
3. 价值定价（按客户价值）

## 🎨 品牌 3 要素

使命 / 愿景 / 价值观

## 📊 营销 5 指标

| 指标 | 健康值 |
|------|--------|
| 流量增长 | > 20%/月 |
| 转化率 | > 2% |
| CAC | 下降趋势 |
| LTV/CAC | > 3 |
| NPS | > 30 |

## 💡 5 大反常识

1. 客户成功 = 营销胜利
2. 少渠道 > 多渠道
3. 内容 ROI 滞后 6-12 月
4. 创始人 IP > 公司品牌
5. 不做品牌 = 长期价格战

## 💡 1 句话

> GTM = ICP + 价值 + 渠道。
> 客户成功 = 营销胜利。
