# 场景化AI创业方法论 - 快速参考

## 🎯 4 阶段产品定位

```
-1 (方向未明) → 0 (MVP) → 1 (PMF) → 规模复制
   ↓                ↓          ↓
 找真问题         验证留存     复购 + 增长
```

## 🔍 5 维 AI 融合度评分

| 维度 | 1 | 3 | 5 |
|-----|---|---|---|
| 痛点强度 | 可有可无 | 显著低效 | 生死攸关 |
| 流程嵌入 | 独立工具 | 日常工具 | 核心生产 |
| 决策权转移 | 辅助建议 | 半自动 | 端到端 |
| 数据可用性 | 无数据 | 脏数据 | 干净闭环 |
| 价值量化 | 难测 | 部分可测 | 直接省钱 |

**总分**：≥20 全力 / 15-19 尝试 / <15 放弃

## 🔄 数据飞轮 4 要素

```
场景覆盖 → 数据 → 模型 → 用户付费 → 现金流
   ↑________________________↓
```

**L3 数据 = 终极壁垒**（物理规律 + 真实场景）

## 💰 成本 4 象限

```
       低规模难度
          ↑
软件      |  软件+硬件
(纯SaaS)  |  (智能眼镜)
----------|----------  
硬件+服务 |  重资产
(机器人)  |  (储能)
          ↓
       高规模难度
```

**千元级法则**：硬件 < 1000 元 = 消费市场；> 1000 元 = 必须有"省 10 倍人力"故事

## ⚡ 三段商业化验证

| 阶段 | 标志 |
|------|------|
| MVP | 100 种子用户 |
| PMF | 5% 转化 + NPS>30 |
| 规模 | 月留存>80% 或 30天复购 |

## 🚨 5 大反模式

1. ❌ 我有技术找不到场景
2. ❌ 我们要做平台
3. ❌ 数据越多越好
4. ❌ 先把模型做到 SOTA
5. ❌ 烧钱换增长

## ✅ 12 项核心自检

### 需求
- [ ] 客户在用土办法？
- [ ] 年付代价 > 10万？
- [ ] 不解决 6 月内会失败？

### 融合度
- [ ] 5维总分 ≥ 20？
- [ ] 嵌入核心流程？
- [ ] 决策权转移？

### 飞轮
- [ ] 5 自检全过？
- [ ] 6 月可验证？
- [ ] 数据壁垒存在？

### 成本
- [ ] 千元级？
- [ ] 三段验证过？
- [ ] 价格战能扛？

## 🏆 4 心法

1. **从问题出发**（不从技术出发）
2. **嵌入流程**（不做独立工具）
3. **数据是壁垒**（不是成本）
4. **成本靠设计**（不靠偷工）

## 💡 1 句话

> AI 创业终极竞争力 = 场景理解 + 数据积累 + 成本优化
