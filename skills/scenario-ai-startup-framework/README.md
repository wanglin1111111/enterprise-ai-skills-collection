# 场景化AI创业方法论

> 从路演实战提炼的 AI 创业方法论 — 4 大模块 + 12 评估维度 + 1 套自检清单

## 核心观点

**问题决定方向，方向决定生死。**

四句心法：
1. 需求 > 技术
2. 场景 > 概念
3. 数据 > 模型
4. 成本 > 故事

## 5 分钟自检

回答 3 个问题：
1. 我的产品处于 -1 / 0 / 1 哪个阶段？
2. AI × 场景融合度 5 维评分总分是多少？
3. 我的数据飞轮能 6 个月内验证吗？

如果任一答案是否定的，重新读一遍 SKILL.md 对应章节。
