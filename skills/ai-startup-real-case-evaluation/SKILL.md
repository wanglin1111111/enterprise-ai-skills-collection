# AI 创业真实案例实战评估

> **真实项目 9 视角打分 × 冲突识别 × 投资决策 × 跟进动作**
>
> 帮你：
> - 用 9 视角框架评估真实在投/在路演项目
> - 识别视角冲突 = 真实风险
> - 输出可执行的跟进动作（1-3 月）
> - 建立项目 portfolio review 模板

---

## 🎯 核心理念

**实战评估 = 9 视角 + 冲突识别 + 决策矩阵。**

3 大陷阱：
1. **单一视角 = 必然盲区**
2. **"投/不投"二分法 = 信息丢失**
3. **无跟进动作 = 评估流于形式**

实战评估要解决：
- 评分（量化）
- 冲突（识别风险）
- 决策（有条件）
- 跟进（可执行）

---

## 📋 9 视角评估清单

### 1️⃣ 创始人视角（场景化 AI 创业）
- 需求金字塔：-1/0/1
- AI×场景融合度：5 维
- 数据飞轮：L1/L2/L3
- 成本平衡：千元级法则

### 2️⃣ 投资人视角（6 维评分卡）
- 痛点真实度 / 解决方案 / 团队 / 市场 / 模式 / 壁垒
- 5 分钟信号提取
- 决策矩阵 + 红线检查

### 3️⃣ 孵化器视角（5 层生态）
- 5 大健康指标
- 阶段性支持
- 校友价值

### 4️⃣ 政策视角（4 政策维度）
- 监管沙盒
- 数据合规
- 知识产权
- 地缘政治

### 5️⃣ 学术视角（AI 方法论）
- 方法先进性
- 数据价值

### 6️⃣ CTO 视角（4 阶段架构）
- 4 维技术债
- 团队搭建
- DORA 指标
- 安全 + FinOps

### 7️⃣ CMO 视角（GTM）
- ICP 5 维
- 4 GTM 模式
- 6 获客渠道
- 3 增长飞轮

### 8️⃣ COO/CFO 视角（运营 + 财务）
- 4 阶段组织
- 3 大报表
- 现金流 3 原则
- 5 财务指标

### 9️⃣ 客户成功视角（NPS + 续约）
- 客户 NPS
- 续约率
- 客户反馈

---

## 📊 9 视角加权公式

```
总分 = 创始人×0.20 + 投资人×0.20 + 孵化器×0.10 + 
       政策×0.10 + 学术×0.05 + CTO×0.10 + 
       CMO×0.10 + COO/CFO×0.10 + 客户×0.05
```

### 4 档决策

| 加权分 | 决策 | 行动 |
|--------|------|------|
| ≥ 7.5 | 重点跟进 | 立刻投资 |
| 6.0-7.4 | 重点观察 | 1-3 月验证 |
| 4.5-5.9 | 谨慎参与 | 关键风险解决后 |
| < 4.5 | 不参与 | 转向其他 |

---

## 🔍 冲突识别 4 类

| 冲突 | 处理 |
|------|------|
| 投资人 vs COO/CFO | ROI vs 毛利 → 看长期 |
| 创始人 vs 政策 | 梦想 vs 监管 → 偏政策 |
| CTO vs CMO | 技术 vs 增长 → 看阶段 |
| 学术 vs 商业 | 先进 vs 落地 → 偏商业 |

## 🧪 实战案例：AI 工业检测（已脱敏）

### 项目背景
- 行业：工业 AI
- 阶段：Pre-A（融资 2000 万）
- 团队：8 人
- ARR：300 万

### 9 视角评分

| 视角 | 评分 | 关键 |
|------|------|------|
| 创始人 | 7.6 | 需求真实 |
| 投资人 | 7.0 | 6 维 41 A 级 |
| 孵化器 | 6.0 | 健康需加速 |
| 政策 | 7.6 | 友好 |
| 学术 | 6.5 | 主流 |
| CTO | 6.0 | 技术债中等 |
| CMO | 7.0 | 客户转介强 |
| COO/CFO | 6.0 | 跑道 18 月 |
| 客户 | 5.0 | 数据少 |

### 加权总分
```
7.6×0.20 + 7.0×0.20 + 6.0×0.10 + 7.6×0.10 + 
6.5×0.05 + 6.0×0.10 + 7.0×0.10 + 6.0×0.10 + 5.0×0.05
= 1.52 + 1.40 + 0.60 + 0.76 + 0.325 + 0.60 + 0.70 + 0.60 + 0.25
= 6.755
```

### 决策：**A-（重点观察）**

### 关键风险
1. 商业模式偏设备
2. 毛利率 40% 偏低
3. 技术债中等

### 跟进动作
1. 验证 AI 融合度提升
2. 提升毛利率 → 50%+
3. 启动 A 轮准备
4. 招测试 + DevOps

### 投资组合策略

- **重点跟进 (≥7.5)**：加投 + 资源倾斜
- **重点观察 (6.0-7.4)**：保持 + 持续验证
- **谨慎参与 (4.5-5.9)**：减投 + 风险监控
- **不参与 (<4.5)**：退出 + 资源释放

## 💡 实战 5 大原则

### 1. 9 视角 = 深度决策
- 5 视角 = 快速评估
- 9 视角 = 深度尽调
- 选对 = 节省时间

### 2. 冲突 = 风险信号
- 不掩盖冲突
- 冲突分析 = 找到真实问题
- 冲突解决 = 提升项目

### 3. 有条件 = 留余地
- 不只"投/不投"
- "有条件投" = 表达不确定性
- 给跟进动作 = 体现专业

### 4. 跟进 = 评估闭环
- 评估 ≠ 结束
- 跟进 1-3 月 = 验证假设
- 调整决策 = 持续优化

### 5. 文档 = 团队学习
- 评估文档化
- 团队共享
- 经验沉淀
