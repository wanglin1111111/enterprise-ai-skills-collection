# AI 创业真实案例实战评估 - 快速参考

## 🎯 实战 4 步法

1. **9 视角评分** (各 0-10)
2. **冲突识别** (4 类)
3. **加权决策** (4 档)
4. **跟进动作** (1-3 月)

## 📊 9 视角加权

```
总分 = 创始人×0.20 + 投资人×0.20 + 孵化器×0.10 + 
       政策×0.10 + 学术×0.05 + CTO×0.10 + 
       CMO×0.10 + COO/CFO×0.10 + 客户×0.05
```

## 🎯 4 档决策

| 加权分 | 决策 | 行动 |
|--------|------|------|
| ≥ 7.5 | 重点跟进 | 立刻投资 |
| 6.0-7.4 | 重点观察 | 1-3 月验证 |
| 4.5-5.9 | 谨慎参与 | 风险解决后 |
| < 4.5 | 不参与 | 转向其他 |

## 🔍 4 类冲突

- 投资人 vs COO/CFO：ROI vs 毛利
- 创始人 vs 政策：梦想 vs 监管
- CTO vs CMO：技术 vs 增长
- 学术 vs 商业：先进 vs 落地

## 🧪 实战案例

AI 工业检测（脱敏）：
- 9 视角分 = 6.755
- 决策 = 重点观察 (A-)
- 关键风险：商业模式 + 毛利率 + 技术债
- 跟进：验证 AI + 提升毛利 + 招测试

## 💼 Portfolio Review

- 重点跟进 (≥7.5)：加投
- 重点观察 (6.0-7.4)：保持
- 谨慎参与 (4.5-5.9)：减投
- 不参与 (<4.5)：退出

## 💡 5 大原则

1. 9 视角 = 深度决策
2. 冲突 = 风险信号
3. 有条件 = 留余地
4. 跟进 = 评估闭环
5. 文档 = 团队学习

## 💡 1 句话

> 不只给"投/不投"，给"有条件投 + 行动"。
