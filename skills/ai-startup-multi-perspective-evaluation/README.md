# AI 创业多视角评估手册（元技能）

> 4 视角交叉验证 + 5 视角加权 + 跨视角综合决策

## 核心观点

**单一视角 = 必然盲区。**
**4 视角交叉验证 = 接近真相。**

## 5 视角技能

1. 创始人：scenario-ai-startup-framework
2. 投资人：investor-pitch-evaluation-framework
3. 孵化器：startup-ecosystem-operating-model
4. 政策：ai-startup-policy-trend
5. 学术：ai-driven-economic-research

## 加权公式

```
总分 = 创始人×0.25 + 投资人×0.30 + 孵化器×0.20 + 政策×0.15 + 学术×0.10
```

## 4 档决策

| 加权分 | 决策 |
|--------|------|
| ≥ 7.5 | 重点跟进 |
| 6.0-7.4 | 重点观察 |
| 4.5-5.9 | 谨慎参与 |
| < 4.5 | 不参与 |
