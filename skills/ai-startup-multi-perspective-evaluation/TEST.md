# 测试案例 — AI 创业多视角评估手册

## 案例 1：AI 智能硬件（脱敏）

### 项目背景
AI 陪伴硬件，情感识别 + 多模态交互，种子轮融资中

### 5 视角评估

| 视角 | 评分 | 关键依据 |
|------|------|---------|
| 创始人 | 8/10 | 需求真实（自闭症儿童） |
| 投资人 | 7/10 | 6 维评分 42/60 = A |
| 孵化器 | 6/10 | 存活率 65% |
| 政策 | 5/10 | 医疗器械方向 |
| 学术 | 7/10 | 主流方法论 |

### 加权计算
```
总分 = 8×0.25 + 7×0.30 + 6×0.20 + 5×0.15 + 7×0.10
     = 2.0 + 2.1 + 1.2 + 0.75 + 0.7
     = 6.75 (B+)
```

### 决策
**重点观察**（1-3 月持续验证）

### 关键风险
- 硬件供应链
- 医疗器械证（耗时）
- 创始人硬件背景弱

## 案例 3：AI 教育平台（脱敏）

### 项目背景
K12 大模型 + 答疑辅导 + 备课助手

### 5 视角评估

| 视角 | 评分 | 关键依据 |
|------|------|---------|
| 创始人 | 5/10 | 商业化未跑通 |
| 投资人 | 6/10 | 6 维评分 38/60 = A |
| 孵化器 | 5/10 | 政策风险高 |
| 政策 | 3/10 | 双减 + 未保 |
| 学术 | 6/10 | 主流方法论 |

### 加权计算
```
总分 = 5×0.25 + 6×0.30 + 5×0.20 + 3×0.15 + 6×0.10
     = 1.25 + 1.8 + 1.0 + 0.45 + 0.6
     = 5.1 (C+)
```

### 决策
**谨慎参与**（政策风险解决后再投）

### 关键风险
- 双减政策影响
- 未成年人保护合规
- 学校采购周期长
- 家长付费意愿不强

### 冲突识别
- 投资人视角（6）vs 政策视角（3）= 严重冲突
- 冲突原因：投资人对政策风险低估
- 处理：偏政策视角
