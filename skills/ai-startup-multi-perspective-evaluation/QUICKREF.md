# AI 创业多视角评估手册 — 快速参考

## 🧩 5 视角技能

| 视角 | 技能 | 核心问题 |
|------|------|---------|
| 创始人 | scenario-ai-startup-framework | 能不能跑通？ |
| 投资人 | investor-pitch-evaluation-framework | 值不值得投？ |
| 孵化器 | startup-ecosystem-operating-model | 能不能长大？ |
| 政策 | ai-startup-policy-trend | 能不能持续？ |
| 学术 | ai-driven-economic-research | 方法是否先进？ |

## 📊 5 视角评分卡

每视角 0-10 分，5 视角加权：

```
总分 = 创始人×0.25 + 投资人×0.30 + 孵化器×0.20 + 政策×0.15 + 学术×0.10
```

## 🎯 4 档决策

| 加权分 | 决策 | 行动 |
|--------|------|------|
| ≥ 7.5 | 重点跟进 | 立刻投/全力支持 |
| 6.0-7.4 | 重点观察 | 1-3 月持续验证 |
| 4.5-5.9 | 谨慎参与 | 关键风险解决后再投 |
| < 4.5 | 不参与 | 转向其他项目 |

## 🔍 4 视角冲突处理

| 冲突 | 处理 |
|------|------|
| 创始人 vs 投资人 | 看团队 vs 看市场 → 偏团队 |
| 创始人 vs 政策 | 看梦想 vs 看监管 → 偏政策 |
| 投资人 vs 孵化器 | 看 ROI vs 看成长 → 看长周期 |
| 政策 vs 学术 | 看合规 vs 看先进 → 偏政策 |

## 🔍 5 视角盲区对冲

| 视角 | 自带盲区 | 对冲视角 |
|------|---------|---------|
| 投资人 | 团队 | 创始人 |
| 创始人 | 市场 | 投资人 |
| 政策 | 技术 | 学术 |
| 孵化器 | 政策 | 政策 |
| 学术 | 商业 | 投资人 |

## 🛠️ 评估流程

```
1. 单视角独立评估（30 分钟/视角）
2. 交叉对比（找矛盾点）
3. 盲区识别（哪一视角缺失）
4. 加权打分（公式）
5. 综合决策（4 档）
```

## 🧪 实战案例

AI 智能硬件（脱敏）：
- 创始人 8 + 投资人 7 + 孵化器 6 + 政策 5 + 学术 7
- 加权 = 6.85 (B+)
- 决策 = 重点观察

## 💡 元方法论

1. **视角权重可调**：投资人偏重 = 投/不投
2. **视角组合可裁剪**：资源有限 = 2-3 视角
3. **视角顺序有意义**：先政策（生存）→ 后其他
4. **视角冲突要正视**：冲突 = 真实风险

## 💡 1 句话

> 单一视角 = 必然盲区。
> 5 视角加权 = 完整决策。
